# Fichas de cliente

Um arquivo por cliente: `.claude/trafego/clientes/<cliente>.md`. A Ada lê a ficha antes de analisar a conta.

Conteúdo sugerido: nicho, contas de anúncio (IDs), ticket, dashboard/plataforma de venda (Hubla, Hotmart...), padrão de nomenclatura e UTM, histórico do que funcionou e do que não funcionou.

Não coloque token, senha ou chave de API aqui.
